# Dashboard example

Synthetic `auto-enum.sh` output for previewing
[`aranumtoolkit/network/report-dashboard.py`](../../../network/report-dashboard.py) without
running a live engagement.

## Generate + view (one-liner)

From the repo root:

```bash
python3 aranumtoolkit/network/report-dashboard.py --output aranumtoolkit/docs/examples/dashboard/output aranumtoolkit/docs/examples/dashboard/fixture && xdg-open aranumtoolkit/docs/examples/dashboard/output/index.html
```

On macOS replace `xdg-open` with `open`. On a remote host without a display,
serve the output briefly instead:

```bash
python3 aranumtoolkit/network/report-dashboard.py --output aranumtoolkit/docs/examples/dashboard/output aranumtoolkit/docs/examples/dashboard/fixture && \
  ( cd aranumtoolkit/docs/examples/dashboard/output && python3 -m http.server 8765 )
```

…then browse to `http://localhost:8765/`.

## What the fixture covers

| Service | Hosts | Severity tiers exercised |
|---|---|---|
| `smb`   | 10.0.0.5, 10.0.0.7 | CRITICAL (`guest:guest`), HIGH (`UNAUTH SMB shares`), MEDIUM (signing disabled) |
| `http`  | 10.0.0.5, 10.0.0.20, 10.0.0.30 | CRITICAL (`UNAUTH: Jenkins API exposed`), HIGH (`UNAUTH: Proxmox version API`), MEDIUM (BMC iLO, Confluence, Proxmox detected) |
| `vault` | 10.0.0.50 | (no severity rule for plain `Vault reachable:` — appears on host page + coverage matrix but not on severity views) |

11 severity-tagged findings total across 6 hosts. Demonstrates every page in
the dashboard:

- Severity tiles (`index.html`)
- Sortable host / service tables (`hosts.html`, `services.html`)
- Per-host detail (`host_10.0.0.20.html`, etc.) with severity-grouped finding tables
- Per-service detail (`service_http.html`, etc.)
- Severity-filtered views (`severity_critical.html`, etc.)
- Run-log timeline (`timeline.html`)
- Coverage matrix (`coverage.html`)
- Client-side search payload (`data.json`)

## Editing the fixture

The fixture mimics the real `auto-enum.sh` output layout. To add new findings,
append severity-rule-matching lines to a service's `_dispatcher.log` — see
[`aranumtoolkit/network/report.py`](../../../network/report.py) for the full rule catalogue.
